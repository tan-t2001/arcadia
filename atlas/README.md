# 阿卡迪亚世界图志

本地互动地图、Three.js 三维世界与概念素材审阅网页。主地图使用第 3 版，包含 15 个地点、19 幅当前概念图。三维世界按各地概念图细化建筑、陈设、材质与植被，支持环绕查看和自由飞行。所有运行资源均存放在本目录。

## 打开

Windows 可双击 `打开3D世界.cmd`，自动启动本地服务并打开三维世界。macOS 可使用 `打开地图.command`。也可在本目录执行

```sh
python server.py --open --view world3d
```

浏览器打开 <http://127.0.0.1:4173>。关闭运行窗口或按 Ctrl+C 可停止。

也可直接打开 `index.html`，点击顶部“3D 世界”。三维依赖可通过本地文件加载，支持离线使用。直接打开时，修改建议保存在当前浏览器。使用本地服务时，建议还会写入 `feedback/revisions.json`。

## 使用

- 点击地图地标或左侧目录，阅读扩写地方志、概念图、建造约定和地理视线说明。
- 拖动/双指缩放地图，或使用右侧缩放、复位、地名和沉浸按钮。
- “地点图鉴”集中展示 19 幅概念；图片可放大和下载原图。
- “提修改建议”可选择地点、素材、类别与优先级，并在图片上标记一个位置。
- “修订手札”显示建议、处理状态与素材确认进度，可以导出 JSON。
- 素材确认以当前世界版本为单位，记录审阅状态。三维场景用于空间探索和继续核对布局。

## 3D 世界

- 左键拖动旋转，WASD 或方向键沿地面平移，Shift 加速，滚轮缩放。键盘平移速度随观看距离调整。触屏支持单指旋转、双指缩放和平移。
- 从顶部地点选择框、场景地名、左侧索引或小地图前往任意地点。概念详情也有三维入口，三维场景的“地方志”可打开相应素材。
- “从这里飞行”会切换到近景。WASD 或方向键移动，Q 下降、E 上升、Shift 加速，按住左键转头。“锁定视角”支持鼠标持续转头，Esc 回到环绕模式。
- 飞行速度提供 8、35、120、450 m/s 四档。触屏显示方向与升降按钮。
- 支持晴昼与暖暮、三档画质、地名显隐和沉浸视图。轻盈画质关闭阴影并降低渲染分辨率。
- 地精聚落南侧洞口通向可进入的居住巷道。普通建筑主要表现外观，当前飞行支持穿行观察，建筑碰撞和完整室内尚待后续制作。

三维场景以 `world.js`、原始设定、补充设定和当前概念图为依据。建筑使用米制约定。A4 地图是压缩距离的图面构图，三维大陆具有岬角、海湾、沙滩与连续海岸。普莱恩三个街区相连，两座要塞分居同一河段两岸，山脊位于普莱恩西侧。地精部落位于西南远方林谷，四季神殿位于东北远方山地，由长途道路连接。

本轮补入砂岩砌缝与木纹、斗兽场双层拱券、船帆与索具、鱼架渔网、矿车吊架、葡萄藤与果串、二十间商铺的不同货物、教堂彩窗、苔石藤蔓和四季植被、地精圆门草屋与矿道木撑。植被按河岸、荒漠、林地及山地分布。具体大陆外形、路程数值和概念图未展示的背面细节属于可修改的程序化建模解释。

## 文件

| 文件/目录 | 用途 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 本地网页与交互 |
| `world.js` | 地点文字、热点位置、材料、平面模块、镜头与视线约束 |
| `world3d-model.js` | 连续地形、水系、道路与全部地点的程序化三维模型 |
| `world3d.js` / `world3d.css` | 三维加载、相机、地点联动、小地图与界面 |

| `打开3D世界.cmd` | Windows 三维网页启动入口 |
| `assets/map-v3.png` | 当前卷轴地图 |
| `assets/concepts/` | 生成概念原图及历史版本 |
| `assets/previews/` / `assets/thumbs/` | 网页用压缩版本；原图不变 |
| `art-direction/assets.json` | 当前素材版本清单 |
| `art-direction/prompts.json` | 使用内置 imagegen 的全部生成/修订提示词与参考关系 |
| `art-direction/world-model.json` | 后续建模可读取的世界与局部布局约定 |
| `../refs/设定-补充版.md` | 原设定之外的本轮补充；原 `设定.md` 未修改 |
| `feedback/revisions.json` | 启动本地服务后保存的修改意见 |

## 后续接入

本地服务仅监听本机。`GET /api/feedback` 返回 `{ "records": [...] }`；`POST /api/feedback` 按记录 ID 保存或更新建议。记录包含 `location`、`image`、`imageVersion`、`version`、`category`、`priority`、`message`、`point`、`status`、`createdAt`、`updatedAt` 与 `action`。图片标点 `point` 为 0–1 归一化坐标。服务验证字段长度、来源和内容类型，保存使用原子替换。

修改意见保留在本机，不会自动发送给聊天或第三方。下一轮可直接读取 `feedback/revisions.json`，或将导出的手札用于修订。

尺寸与布局是可编辑的建模提案。现可通过三维场景核对体块、河岸、山脉遮挡与相邻地标，继续细化建筑结构和材质。地图地标采用示意比例。

## 检查

```sh
npm run check
```

检查 JavaScript 语法、地点和素材完整性、视线档案、邻接关系及 20 店铺/16 色配置。三维检查还会实际构建模型，验证实例数据、四间出生村房屋、二十店铺、酒店地基、下挖矿坑、隔河要塞、城内邻接、山脊、自然海岸及远方聚落距离。浏览器运行需要 WebGL 支持，Python 3 用于本地服务与保存建议，Node 用于检查。
